本机分析与项目文件

常规 WB、染色图像和 qPCR 的导入、计算和本地保存由你的设备完成，核心分析不要求创建账号。原始图像或表格、样本标签、ROI、参数和结果保存在应用本机存储，或保存在你主动导出的项目文件中。首版不提供实验项目云上传或云同步；导出文件请自行保管备份，删除应用或清除站点数据可能影响本机项目。

Core analysis and local project operations run on your device without an account. Projects live in local storage or files you export. This edition has no cloud project upload or sync; keep independent backups.

免账号版本

当前版本移除注册、登录和账号管理功能，不向账号服务发送请求，不上传或同步实验项目。升级时仅清理旧版账号令牌所在的专用存储键，不删除本机实验项目、语言选择或你导出的文件。

This edition has no registration, sign-in or account management and makes no account-service requests. Experiments are not uploaded or synchronized. Upgrading clears only the old account-token storage keys; local projects, language preferences and exported files are kept.

历史账号与备份

旧版本曾提供可选账号，服务器保存账号标识、用户名、密码哈希及必要服务记录。2026年10月25日起，线上账号接口关闭，账号服务停止，原数据库私密保留以处理历史资料请求。移除新版账号入口不代表这些历史记录及备份已被删除。有关访问、更正或删除旧账号资料，请联系隐私邮箱，不要发送密码。本机项目不属于服务器账号资料。

已有备份保留约定继续有效：停止生成每周新备份，现有自动备份仍由独立的每日任务清理，正常运行时在约 14 天内过期；2026年10月20日及此前创建的历史手工账号备份及其已确认副本，将在 2026年11月20日复核后删除；2026年10月22日部署前手工账号备份及其已确认副本，将于 2026年11月5日复核清理。带账号版本的源码存档不包含真实账号数据库、密码、令牌或服务器密钥。旧数据库在核对已删除账号记录前不得恢复为公开账号服务。

Older editions offered optional accounts. On October 25, 2026 the public account API and backend service were disabled. The original database remains private for legacy-data requests. Removing account controls does not erase historical account records or backups. Contact the privacy address for access, correction or deletion requests, without sending passwords. Existing commitments remain: no new weekly backups while the service is disabled; existing automatic backups continue expiring within about 14 days through the independent daily task during normal operation; identified manual backups from October 20, 2026 or earlier are reviewed and deleted on November 20, 2026; the October 22 pre-deployment backup and identified copies are reviewed and deleted on November 5, 2026. The source-code archive contains no real account database, credentials or server secrets. Restored account databases must not be reopened publicly before deletion records have been reconciled.

The legacy account service is hosted on Alibaba Cloud in Silicon Valley, USA. This account-free edition makes no account requests. Account-service logs roll over about every 5 days (IP recorded, authenticated user IDs not). The site keeps no access logs; system components follow OS defaults.

可选 AI 服务

PCR 的可选 AI 解读由你自己配置服务地址、模型和 API Key，并只在主动点击解读时发送结构化分析摘要。摘要可能包含样本名、基因名、实验设置、质量提示与计算结果，不等同于匿名数据；所选服务的处理和保留规则由该服务决定。记住 AI 配置时密钥保存在本机应用存储（不是加密保险箱），项目导出不包含该密钥。请勿把敏感标识或无权分享的内容发送给 AI 服务；桌面版仅允许连接内置白名单中的服务地址。

Optional PCR AI interpretation sends a structured summary (possibly sample and gene names, settings and results) to a provider you configure with your own API key; these data are not necessarily anonymous and provider policies apply. Remembered keys stay in local app storage and never enter project exports.
