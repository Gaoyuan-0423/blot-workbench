本机分析与项目文件

常规 WB、染色图像和 qPCR 的导入、计算和本地保存由你的设备完成，核心分析不要求创建账号。原始图像或表格、样本标签、ROI、参数和结果保存在应用本机存储，或保存在你主动导出的项目文件中。首版不提供实验项目云上传或云同步；导出文件请自行保管备份，删除应用或清除站点数据可能影响本机项目。

Core analysis and local project operations run on your device without an account. Projects live in local storage or files you export. This edition has no cloud project upload or sync; keep independent backups.

免账号版本

当前版本移除注册、登录和账号管理功能，不向账号服务发送请求，不向 WispLab 服务器上传或同步实验项目。用户主动调用可选 AI 时的数据传输见下文。升级时仅清理旧版账号令牌所在的专用存储键，不删除本机实验项目、语言选择或你导出的文件。

This edition has no registration, sign-in or account management and makes no account-service requests. Experimental projects are not uploaded or synchronized to WispLab servers. Data sent by explicitly invoked optional AI features is described below. Upgrading clears only the old account-token storage keys; local projects, language preferences and exported files are kept.

历史账号与备份

旧版本曾提供可选账号，服务器保存账号标识、用户名、密码哈希及必要服务记录。2026年10月25日起，线上账号接口关闭，账号服务停止，原数据库私密保留以处理历史资料请求。移除新版账号入口不代表这些历史记录及备份已被删除。有关访问、更正或删除旧账号资料，请联系隐私邮箱，不要发送密码。本机项目不属于服务器账号资料。

已有备份保留约定继续有效：停止生成每周新备份，现有自动备份仍由独立的每日任务清理，正常运行时在约 14 天内过期；2026年10月20日及此前创建的历史手工账号备份及其已确认副本，将在 2026年11月20日复核后删除；2026年10月22日部署前手工账号备份及其已确认副本，将于 2026年11月5日复核清理。带账号版本的源码存档不包含真实账号数据库、密码、令牌或服务器密钥。旧数据库在核对已删除账号记录前不得恢复为公开账号服务。

Older editions offered optional accounts. On October 25, 2026 the public account API and backend service were disabled. The original database remains private for legacy-data requests. Removing account controls does not erase historical account records or backups. Contact the privacy address for access, correction or deletion requests, without sending passwords. Existing commitments remain: no new weekly backups while the service is disabled; existing automatic backups continue expiring within about 14 days through the independent daily task during normal operation; identified manual backups from October 20, 2026 or earlier are reviewed and deleted on November 20, 2026; the October 22 pre-deployment backup and identified copies are reviewed and deleted on November 5, 2026. The source-code archive contains no real account database, credentials or server secrets. Restored account databases must not be reopened publicly before deletion records have been reconciled.

可选 AI 服务

WB 完整工作区的“视觉服务（自带 API）”由你自己配置服务地址、模型和 API Key。只有主动发起视觉候选请求时，才从网页或桌面应用直接向所选服务发送当前图像的降采样预览（8 位灰度 PNG）、泳道标签、数量和信号极性；批量请求会逐张处理所选图像。图像和标签可能包含实验信息，不等同于匿名数字摘要。默认本地取样和像素测量不依赖此功能，返回候选仍需人工复核。单独的“发送合成图测试”只发送内置合成小图及测试提示，不发送当前项目图像或标签。

In the full WB workspace, Vision service (your own API) uses the service address, model and API key you configure. Only an explicitly invoked vision-candidate request sends a downscaled preview of the current image (8-bit grayscale PNG), lane labels, lane count and signal polarity directly from the website or desktop app to the selected service; batch requests process selected images individually. Images and labels may contain experimental information, not merely anonymous numbers. Default local region proposals and pixel measurements do not require this feature, and returned candidates need manual review. The separate Send synthetic test action sends only a built-in synthetic image and test prompt, not current project images or labels.

WB 视觉服务配置默认仅保存在当前页面内存中，刷新即清除；选择“在此设备记住”才会将服务地址、模型和密钥以明文写入本机 localStorage。已记住的副本会持续保留，需点击“清除已保存”删除；仅取消勾选并保存不会删除已有副本。请求会使用该密钥向所选服务认证，密钥不进入项目导出。所选供应商的数据处理、保留及计费受其政策和你与其的约定约束；本机取消或超时不保证已送达请求未被处理或计费。请勿在共用设备上记住密钥。

WB vision settings stay in current-page memory by default and clear on refresh. Selecting Remember on this device writes the service address, model and key as plaintext to localStorage. An existing remembered copy remains until Clear saved is used; unchecking the option and saving does not remove an earlier copy. Requests use the key to authenticate with the selected service; project exports exclude it. The provider's processing, retention and billing follow its policies and your agreement with it. Local cancellation or timeout does not guarantee a delivered request was not processed or billed. Do not remember keys on shared devices.

PCR 的可选 AI 解读由你自己配置服务地址、模型和 API Key，并只在主动点击解读时发送结构化分析摘要。摘要可能包含样本名、基因名、实验设置、质量提示与计算结果，不等同于匿名数据；所选服务的处理和保留规则由该服务决定。记住 AI 配置时密钥保存在本机应用存储（不是加密保险箱），项目导出不包含该密钥。请勿把敏感标识或无权分享的内容发送给 AI 服务；桌面版仅允许连接内置白名单中的服务地址。

Optional PCR AI interpretation sends a structured summary (possibly sample and gene names, settings and results) to a provider you configure with your own API key; these data are not necessarily anonymous and provider policies apply. Remembered keys stay in local app storage and never enter project exports.
