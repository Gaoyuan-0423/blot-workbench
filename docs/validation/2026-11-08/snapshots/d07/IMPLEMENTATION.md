## 实现范围

- `AnalysisResult.ifAnalysis` 是规范 IF 结果，保存整图和每个矩形区域的实际半开像素范围、像素数、各通道阳性/并集/交集计数、实际背景/阈值、Pearson、Manders 分子分母及未定义原因。
- 整图背景和阈值只计算一次，固定应用各 ROI。Pearson 全区域与阳性并集掩膜分别计算；M1 分母为区域全部 A 强度，M2 对称。没有逐 ROI 重新估计阈值，也没有把多个 ROI 的系数当成独立生物重复。
- 原始矩形逐参数四舍五入后与图像取真实交集；空交集保留为零像素。无定义 Pearson 和零分母 Manders 在规范结果中为 `null`，显示原因并在 CSV/Excel 中留空。
- 原有 `coloc` 数值与叠加层约定保留为兼容结果；新 UI/API/导出优先使用规范结构。旧结果没有的 ROI、计数和分母不会自动补造，旧染色占位指标不能变成新 IF 样本。
- `ifSamples` 单独保存每次整图及全部 ROI、来源 SHA-256、自有配置和图像元数据；分组是描述标签。原图缺失明确列入完整性报告，不能假定可复算。
- 可从历史 IF 记录载入原文件及保存配置，重新运行 Worker；项目导入后保存的分析值也是历史，不能直接冒充当前结果。参数或 ROI 改变时，当前显示、API 和保存入口共享有效性检查。
- API、专用 IF CSV、Excel 当前/历史 IF 表及中英文 Methods 保留相同范围和实际数值。历史记录使用各自设置；Methods 较长时分行保存，避免 Excel 单格长度限制截断。
- IF 体检提示与新范围一致：不建议加入染色样本库做组间检验，不发核分割建议；未定义系数不解释为低相关，低 Pearson 不单独判断生物学共定位，也不按预期结果调整阈值。已有单位统计提示同步使用独立单位，不以图像数建议样本量，不把普通 ANOVA 称为异方差稳健。
- 归档检查覆盖原文件哈希、记录/附件 ID、配置与实际手动阈值、ROI 与实际裁切范围、各计数关系、Manders 分子分母、未定义原因及历史来源结果一致性。IF 归档使用与计算核心相同的越界裁切规则。
