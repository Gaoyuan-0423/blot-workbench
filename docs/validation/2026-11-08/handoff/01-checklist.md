## 4. 已实现机制的准确边界

### IF

已实现整图与矩形 ROI 的 Pearson（全部像素/掩膜像素）、Manders M1/M2，以及区域几何、背景、阈值、掩膜与像素计数、未定义原因的记录。专用 IF 记录可以保存、恢复与重新计算；旧结果不会在未重算时自动变成当前结果。

独立单位统计有两种估计方式：整图模式每视野取整图系数；选区模式对明确选定且同图内不重叠的 ROI 系数取算术等权均值，然后去重视野、切片内视野等权、单位内切片等权。**这是系数的层级均值；不是合并像素后重新计算的系数，不按 ROI 面积加权，也不做 Fisher z 变换。** 任一选定 ROI 当前指标缺失，会使该视野及单位当前指标为空；不补零或重新分配权重。

重复视野不增加独立 n；来源、单位、分组、配置或 ROI 冲突会阻止推断。修改指标、选区、映射、分组、纳排或记录集合会撤销确认。显式确认的独立组设计才可能获得推断资格；配对/重复测量仍不支持。确认和配置一致不能证明生物学独立性、采集可比或 ROI 选择无偏。

当前 IF 图像测量仍是 RGB 通路。能读入某些 TIFF 不代表保留原始高位深进行定量；原始多通道和 C/Z/T 轴的完整支持未完成。D07 的 17 张 IF 图是厂商 RGB 示例，不是新的原始多通道实验。

### qPCR 与染色分析

qPCR 已按确认的实验单位汇总技术测量，进行单位级统计并区分 nBio/nTech。跨板同名不应自动认定同一个体；旧项目不自动获得设计确认。配对/重复测量目前明确不支持。

qPCR 的 AI 解读已经与当前分析和模型选择绑定；变更后旧卡片卸载、中止请求。不能把 D09 部分实现说成完全没有保护；也不能把它说成已完成所有迟到响应和报告来源验收。没有通过真实外部模型调用评价解释质量。

IHC/H&E/Masson 已接入来源—视野—切片—独立单位统计。H-DAB 面积的一致性证据不能推广为 H-score、核计数、HE 或 Masson 的全部科学准确性证明。

## 7. 论文研究主张与评价框架

建议检验的主张：明确的实验单位、配置与结果关联、冲突检查，是否能减少用户最终提交的实质分析错误，同时保持正确完成率和合理操作负担。此主张尚未由真实用户任务证明。

分三层记录：L1 固定输入与方法定义的数值核验；L2 预先裁定的故障、无故障和合法变化案例；L3 独立用户完成真实分析任务。每层使用自己的分母与终点。

未来比较应区分相同引擎的机制消融和外部工具任务基准。最终结局至少区分正确完成、错误提交、合理中止/需复核、技术失败/超时，避免靠全部阻断取得“零错误”。裁定规则先冻结，分歧应有独立处理；任务、使用者和生物来源的聚类不能忽略。

历史 PLAN 中的“12 个基础任务、8 名使用者”等仅为讨论用 pilot 排期示例，没有实际参与者或结果，也不是期刊规定的样本量。正式样本量应由预期改善、变异与任务设计确定。

如要重写论文，先取得预印本正文和对应历史结果，逐项核对“原稿主张—当前新增实现—新增证据—尚缺证据”。不要凭本交接推测原稿全文，不虚构新颖性、用户收益、实验结果或录用概率。
