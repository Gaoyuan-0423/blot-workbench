# v0.1.0-alpha.1 — 2026-10-10

**纯合成数据的网页流程演示 / Synthetic-data browser workflow demonstration**

这是 Blot Workbench / 印迹工作台的首个 alpha 版本。可打开[在线演示](https://gaoyuan-0423.github.io/blot-workbench/)或查看[公开源码](https://github.com/Gaoyuan-0423/blot-workbench)。版本归档、最终 tag/提交和构建证据以 [GitHub 预发布记录](https://github.com/Gaoyuan-0423/blot-workbench/releases/tag/v0.1.0-alpha.1)为准。作者：Gaoyuan；许可证：MIT。

## 范围

- 一个项目容纳 2 个批次及 8 张合成目标/内参曝光图。
- 6 个稳定样本 ID 和 6 个实验单位，展示重复测量关系。
- ROI/内参配对审阅、分析失效状态、模板快照与恢复流程。
- 预置数值的分层展示、项目包与 CSV 体验、中英界面。
- 示例包含 8 张原始合成 PNG、未确认项目包和确认 7 张可用图后产生的 18 行预期 CSV；饱和图不会生成有效结果。
- MIT 许可证、引用元数据、方法/隐私/验证文档及贡献入口。

## 已知限制

数值是合成生成器在固定默认 ROI 下的示例测量，不会随编辑重新测量；真实 TIFF/PNG 导入、通用图像定量、统计检验、基础组图、IF、桌面安装包与 Wisp 插件均未实现。质量标签为合成场景设定。浏览器只保存当前工作区且不是备份，建议导出项目包。

ROI 或配对修改后，预置结果必须失效；当前版本不提供真实重新定量。演示包的兼容范围是本版本的数据结构，未来升级需有明确迁移策略。

已记录的系统/浏览器覆盖为 Windows/macOS × Chrome/Edge，不包括所有浏览器和系统版本。实际检查见[验证记录](../validation.md)，截图证据见[截图记录](../screenshots/README.md)。

## 验证与部署证据

应用主线提交 [7ea215419f51df283962d62b8ead768a6758caba](https://github.com/Gaoyuan-0423/blot-workbench/commit/7ea215419f51df283962d62b8ead768a6758caba) 的 [CI 运行](https://github.com/Gaoyuan-0423/blot-workbench/actions/runs/38060883807)通过 18 项核心测试、12 项脚本测试和四个系统/浏览器组合各 7 项端到端测试。[Pages 部署运行](https://github.com/Gaoyuan-0423/blot-workbench/actions/runs/38061081294)成功，在线入口已核验。

发布文档合入后会再次运行主线 CI 与部署，最终运行及资产校验信息归档在 GitHub Release。这些检查验证程序和演示流程，不构成真实图像算法、实验结论或科研适用性的验证。

## 希望获得的反馈

多图项目是否易于理解；检查与继续工作的下一步是否清楚；修改后旧结果失效是否容易理解；样本/实验单位是否容易混淆；保存和迁移是否符合实验室使用习惯。

## English summary

The first alpha of Blot Workbench is a synthetic-data Western blot workflow demonstration, dated 2026-10-10, by Gaoyuan under MIT. The [live demo](https://gaoyuan-0423.github.io/blot-workbench/) and public source repository are available. The linked M1 CI run passed 18 core tests, 12 script tests, and 7 end-to-end tests in each Windows/macOS × Chrome/Edge combination; its Pages deployment succeeded. Final version assets and build evidence belong to the [GitHub prerelease record](https://github.com/Gaoyuan-0423/blot-workbench/releases/tag/v0.1.0-alpha.1). This is not an experimental-image quantification tool. Real TIFF/PNG import, statistics, figure composition, IF, desktop packages, and Wisp integration are not included. Workflow tests do not establish scientific validity.
