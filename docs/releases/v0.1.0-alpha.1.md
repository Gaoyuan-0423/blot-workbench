# v0.1.0-alpha.1 — 未发布草稿 / Unreleased draft

**纯合成数据的网页流程演示 / Synthetic-data browser workflow demonstration**

这是 `0.1.0-alpha.1` 的发布说明草稿。[公开仓库](https://github.com/Gaoyuan-0423/blot-workbench)已经建立；GitHub Pages 和 alpha 预发布仍待完成和核验。当前不声称存在正式发布链接、发布日期或 release tag。完成后补充对应提交、部署检查与真实测试结果。

## 范围

- 一个项目容纳 2 个批次及 8 张合成目标/内参曝光图。
- 6 个稳定样本 ID 和 6 个实验单位，展示重复测量关系。
- ROI/内参配对审阅、分析失效状态、模板快照与恢复流程。
- 预置数值的分层展示、项目包与 CSV 体验、中英界面。
- 示例包含 8 张原始合成 PNG、未确认项目包和确认 7 张可用图后产生的 18 行预期 CSV；饱和图不会生成有效结果。
- MIT 许可证、引用元数据、方法/隐私/验证文档及贡献入口。

## 已知限制

数值是合成生成器在固定默认 ROI 下的示例测量，不会随编辑重新测量；真实 TIFF/PNG 导入、通用图像定量、统计检验、基础组图、IF、桌面安装包与 Wisp 插件均未实现。质量标签为合成场景设定。浏览器只保存当前工作区且不是备份，建议导出项目包。

ROI 或配对修改后，预置结果必须失效；当前版本不提供真实重新定量。演示包的兼容范围是本版本的数据结构，未来升级需有明确迁移策略。

Windows 与 macOS 是支持目标，不能据此把所有浏览器组合称为已验证。实际检查见[验证记录](../validation.md)，截图证据见[截图记录](../screenshots/README.md)。

## 希望获得的反馈

多图项目是否易于理解；检查与继续工作的下一步是否清楚；修改后旧结果失效是否容易理解；样本/实验单位是否容易混淆；保存和迁移是否符合实验室使用习惯。

## English draft summary

This draft describes a synthetic-data Western blot workflow alpha with an existing public repository; the hosted demo and prerelease remain pending verification. It is not an experimental-image quantification tool. Real TIFF/PNG import, statistics, figure composition, IF, desktop packages, and Wisp integration are not included. Release and deployment links must be added only after checking them. See the validation record for actual tested environments; no undocumented platform or scientific-validation claim is implied.
