# v0.3.0-alpha.1 — 2026-10-13

**真实图像本机定量预发布 / Local real-image measurement pre-release**

这是首个包含真实图像工作区 `#real` 的预发布版本，由 `0.3.0-dev.1`–`0.3.0-dev.3` 开发预览合并而来。版本归档、最终 tag/提交和构建证据以 [GitHub 预发布记录](https://github.com/Gaoyuan-0423/blot-workbench/releases/tag/v0.3.0-alpha.1)为准。作者：Gaoyuan；许可证：MIT。

## 范围

- 本机批量导入 TIFF/PNG 原图：保留原始字节与 SHA-256，支持有界的 8/16 位无符号格式子集，不支持的格式明确报错。
- 一次说明泳道、批量提出条带/背景候选、手动拖动/缩放与坐标编辑；ROI 修订与复核历史随项目保存。
- 显式实验或个体 N/T 配对；独立样本数来自实验设计和个体编号，不由泳道数、图数或日期推定。
- 归一化基准可选：各自配对对照 = 1，或指定一个对照作共同基准（新项目默认，自动选第一个可用对照）；其他对照保留真实计算差异。
- 可选双侧配对 t 检验：原始目标/内参比值输入，报告实际 n、df、未校正 P、均值差与 95% CI；切换绘图基准不改变 P。
- 中英界面与导出：CSV、统计 CSV、SVG/PNG/TIFF 图形及含原图的项目包；浏览器自动保存与恢复。
- 视觉 API 设置仍只发送内置合成测试图；真实图像分析不发出网络请求。

## 已知限制

真实像素分析仍是实验性预览：端点截断、采集线性、跨膜/批次可比性不会因统计检验消失；自动定位是需人工复核的候选。批量自动无复核分析、技术重复合并、跨膜校准、ANOVA/非参数与多重比较、组图、IF、桌面安装包与 Wisp 插件均未实现。公开网页仍为 `0.1.0-alpha.1`，未部署本版。

## 验证与构建

验证明细见 [validation-real-images](../validation-real-images.md)：本机 macOS/Chrome 通过 103 个单元测试、12 个脚本测试、12 个浏览器流程（含 5 个真实像素/配对流程）、TypeScript 与生产构建；统计夹具对照独立 SciPy 参考值。

tag 指向的 main 提交由远端 CI 验证且全绿：ubuntu 上单元测试、脚本测试与生产构建；Windows 与 macOS × Chrome/Edge 四组运行浏览器流程与视觉 API 套件。发布包 `dist/` 直接取自该次 CI 的 `web-dist` 附件，与本机构建逐文件核对。

下载包为静态网页构建、文档和合成示例，不是桌面安装器；按 `DISTRIBUTION.md` 在本机 HTTP 服务中打开 `dist/`。`SHA256SUMS` 提供 ZIP 与 manifest 的 SHA-256；manifest 逐项列出包内文件、大小和校验值。包内不含任何用户私有图片、结果或凭据。
