# 真实图像分析指南

[English](real-images.en.md) · [合成示例教程](user-guide.md)

`0.3.0-dev.1` 新增独立的真实图像项目工作区。启动本机版本后打开 `#real`，或在旧示例侧栏选择“真实图像分析”。这仍是开发预览，尚未完成独立实验室、固定 ImageJ 流程和全部仪器格式的验证；公开 alpha 网站与既有下载包不会随开发分支自动更新。

## 1. 导入与映射

一次选择或拖入多个 TIFF/PNG。程序在本机解码，不将实验图发送给视觉 API。保留原始字节、文件名、SHA-256 与图像元数据；预览图不会代替原始像素用于测量。

先支持单页、每通道 8/16 位无符号整数的灰度或不透明 RGB/RGBA 图像子集。不支持的编码、页数、透明度、方向或过大文件会明确报告错误，不静默降为 8 位。支持的精确范围及测试证据见[验证记录](validation-real-images.md)。RGB 使用程序记录的灰度转换方法；本版不是多通道荧光定量工具。

文件名中的蛋白和编号只是映射建议。逐行核对蛋白、目标/内参、重复编号、膜与曝光；同一项目可以放入多次实验。多个曝光不能自动变成多个独立重复，配对不唯一时先排除不使用的曝光。日期不决定独立性。

## 2. 一次设置泳道

所有图像使用相同布局时，可填写由左到右的样本标签，如 `NC, siRNA`，应用到整批图片。支持的简明中英文说明会转换成可核对的标签；它不是任意自然语言理解模型。不认识的说明应修改为明确的顺序列表。

可写 `NC, siRNA, marker`；末尾 marker 可不存在于某些图片。右侧额外 marker 不属于实验样本，不参与内参归一化或 n 的计算。自动建议按从左到右寻找所需候选，仍需检查是否将 marker 或非特异条带错认为目标；多排条带或相连泳道可能无法自动正确分开。

确认独立实验以及同膜、同样本的配对关系后，再勾选实验设计确认。标签名称或文件尾号本身不能证明生物学独立性。

## 3. 自动分析与手动调整

运行批量分析，得到条带和局部背景候选。每张图片都能查看叠加框，并手动移动、调整尺寸与背景。自动建议默认保留人工修改过的区域。

计算读取原始解码数组。暗条带净信号为 `条带面积 × 背景均值 − 条带像素总和`；亮条带方向相反。非正净信号不会被改写为零或拿去计算有效比值。条带/背景应互不重叠，背景应代表局部噪声并避开其他信号。修改取样框后重新计算，相关复核状态失效并保留分析历史。

像素达到信号端点会触发截断警告。这可能与曝光、处理或导出有关，不能单凭它确定相机饱和；没有端点像素也不能证明在线性范围内。人工点击“复核”不能消除像素风险。

## 4. 归一化与统计图

先在同次实验、同膜、同泳道配对计算 `目标净信号 / 内参净信号`，再除以该次实验明确标为 `NC`、`control` 或“对照”的唯一泳道比值，得到相对于匹配对照的倍数。因此每次实验的对照都为 1，这是归一化定义，并非证明对照没有生物学变异。

图中展示每个完整重复的数据点及均值 ± 样本标准差（SD）。每个重复编号最多计一次；缺少内参、重复配对歧义或净信号无效的结果不能悄悄补零。未复核、实验设计未确认或存在质量警告时，图和导出保留草稿标记。

本版只提供描述性统计，不自动选择 t 检验/ANOVA、不生成显著性星号。样本数、配对结构和数据变换确定后才适合另行选择推断方法。参见 [GraphPad 配对比值检验说明](https://www.graphpad.com/guides/prism/latest/statistics/stat_interpreting_results_ratio_t_t.htm)。定量仍要求目标和内参的测量处于合适动态范围，见 [Taylor 等人的 WB 定量方法研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3840294/)。

## 5. 导出、保存与恢复

导出 CSV 保留来源、取样方法、归一化中间量、复核及质量状态；统计图支持 SVG、PNG 和 TIFF。图形导出是结果的渲染，不改变测量图像。不要把 TIFF 图形导出当作原始图像位深保真的证据。

真实项目使用独立的项目包与浏览器保存键，包含原始图片和设置；旧合成项目格式仍可在原入口打开。长久保存或跨电脑迁移请导出项目包，浏览器保存不等于备份。项目包可能含私人实验数据，请勿直接上传公开仓库。

可选视觉 API 设置仍只发送内置合成测试图。真实分析的默认自动化使用本机算法，不需要 API Key；没有把实验图片上传给已配置的服务。

本版每幅图仅支持一个对照与每个条件一个泳道、全项目共享布局。多位患者的 N1/T1/N2/T2 组织配对、技术重复合并、跨膜校准及复杂曝光合并尚未建模，不能通过把 N1 改名 NC 来冒充这些设计。拼接图、透明画布和多排非特异条带应回溯源图；不要把展示用拼图当作连续原始泳道。
