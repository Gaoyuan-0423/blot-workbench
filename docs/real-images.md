# 真实图像分析指南

[English](real-images.en.md) · [合成示例教程](user-guide.md)

`0.3.0-dev.2` 新增独立的真实图像项目工作区。启动本机版本后打开 `#real`，或在旧示例侧栏选择“真实图像分析”。这仍是开发预览，尚未完成独立实验室、固定 ImageJ 流程和全部仪器格式的验证；公开 alpha 网站与既有下载包不会随开发分支自动更新。

## 1. 导入与映射

一次选择或拖入多个 TIFF/PNG。程序在本机解码，不将实验图发送给视觉 API。保留原始字节、文件名、SHA-256 与图像元数据；预览图不会代替原始像素用于测量。

先支持单页、每通道 8/16 位无符号整数的灰度或不透明 RGB/RGBA 图像子集。不支持的编码、页数、透明度、方向或过大文件会明确报告错误，不静默降为 8 位。支持的精确范围及测试证据见[验证记录](validation-real-images.md)。RGB 使用程序记录的灰度转换方法；本版不是多通道荧光定量工具。

文件名中的蛋白和编号只是映射建议。逐行核对蛋白、目标/内参、重复编号、膜与曝光；同一项目可以放入多次实验。多个曝光不能自动变成多个独立重复，配对不唯一时先排除不使用的曝光。日期不决定独立性。

## 2. 一次设置泳道

所有图像使用相同布局时，可填写由左到右的样本标签，如 `NC, siRNA`，应用到整批图片。支持的简明中英文说明会转换成可核对的标签；它不是任意自然语言理解模型。不认识的说明应修改为明确的顺序列表。

可写 `NC, siRNA, marker`；末尾 marker 可不存在于某些图片。右侧额外 marker 不属于实验样本，不参与内参归一化或 n 的计算。自动建议按从左到右寻找所需候选，仍需检查是否将 marker 或非特异条带错认为目标；多排条带或相连泳道可能无法自动正确分开。

另一种模式是明确的 **N/T 个体配对**：每行输入 `样本组编号, 个体编号, N 泳道, T 泳道`，例如 `group-1, individual-1, 1, 2`。样本组编号须与图像映射表一致；同一组的目标和内参共用个体表。不同个体使用不同编号，同一个体跨图组重复测量沿用相同编号，不得通过改号增加 n。预览表格后再应用；这一步明确配对关系，不根据文件日期推测。

确认独立实验或不同个体，以及同膜、同样本的目标/内参配对关系后，再勾选实验设计确认。标签名称、图像数量或文件尾号本身不能证明生物学独立性。

## 3. 自动分析与手动调整

运行批量分析，得到条带和局部背景候选。每张图片都能查看叠加框，并手动移动、调整尺寸与背景。自动建议默认保留人工修改过的区域。

计算读取原始解码数组。暗条带净信号为 `条带面积 × 背景均值 − 条带像素总和`；亮条带方向相反。非正净信号不会被改写为零或拿去计算有效比值。条带/背景应互不重叠，背景应代表局部噪声并避开其他信号。修改取样框后重新计算，相关复核状态失效并保留分析历史。

像素达到信号端点会触发截断警告。这可能与曝光、处理或导出有关，不能单凭它确定相机饱和；没有端点像素也不能证明在线性范围内。人工点击“复核”不能消除像素风险。

## 4. 归一化与统计图

每个有效泳道先计算 `目标净信号 / 内参净信号`。目标与内参必须来自同组、同膜、对应样本，并选定无歧义的曝光。然后在“归一化基准”中明确选择：

- **各自配对对照 = 1**：共享布局使用明确标为 `NC`、`control` 或“对照”的唯一泳道；N/T 设计使用该个体的 N。每一对除以自己的对照比值，所以所有对照都是 1，这不是“对照没有变异”的证据。
- **指定一个对照作为共同基准**：选择一个实验的 NC 或个体的 N，所有同蛋白的目标/内参比值除以该对照比值。只有选定对照定义为 1，其他对照的计算差异保留。共同基准只改变数值尺度，不能校准不同膜、曝光或实验批次；本版保留跨实验可比性未验证的草稿提示。

新建项目默认采用**共同基准**：完成设计后自动以第一个可用对照为基准，可随时更改基准或切换回各自配对对照；与默认一致的选择也会被明确记录。旧存档（不含偏好字段）保持匹配对照行为，已保存的策略不受影响。

默认显示柱图，叠加每个完整独立单位的数据点和均值 ± 样本标准差（SD）；可切换配对连线图。每个完整实验或个体最多计一次。缺少内参、重复测量歧义或无效净信号的单位从两组汇总同时排除，不补零。n 是实际纳入的完整单位数，不能从图数推算。未确认独立性时仅称配对组。

**统计检验默认关闭。** 确認独立性与配对设计、恰好两个条件后，可以明确选择双侧配对 t 检验。它使用原始的目标/内参比值，检验处理减对照（N/T 模式为 T−N）的配对差值，**不使用把各自对照设成 1 后的倍数**。因此，对相同有效完整配对，切换绘图基准不改变 P 值。报告实际 n、自由度、未做多重比较校正的 P 值、均值差与 95% CI。质量警告和 DRAFT 可以与探索性检验并存；阻断数据不能进入检验，P 值不解决图像质量问题。

跨膜、曝光和批次可比性限制适用于两种绘图基准及检验本身；将各自对照画成 1 不能校准检验使用的原始比值。

小样本，尤其 n=3 时，很难评估配对差值的近似正态假设；不能为了获得更小的 P 值选择归一化、ROI、排除项或检验。更多条件、非参数检验、技术重复汇总与多重比较校正尚未提供。详见[统计方法与限制](paired-statistics.md)。目标和内参仍需处于适合定量的动态范围，参见 [WB 定量方法研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3840294/)。

## 5. 导出、保存与恢复

导出 CSV 保留来源、取样方法、归一化中间量、复核及质量状态；统计图支持 SVG、PNG 和 TIFF。图形导出是结果的渲染，不改变测量图像。不要把 TIFF 图形导出当作原始图像位深保真的证据。

真实项目使用独立的项目包与浏览器保存键，包含原始图片和设置；旧合成项目格式仍可在原入口打开。长久保存或跨电脑迁移请导出项目包，浏览器保存不等于备份。项目包可能含私人实验数据，请勿直接上传公开仓库。

可选视觉 API 设置仍只发送内置合成测试图。真实分析的默认自动化使用本机算法，不需要 API Key；没有把实验图片上传给已配置的服务。

共享布局模式支持每个条件一个泳道；个体配对模式用明确的 N/T 表支持同图多个个体。技术重复自动合并、跨膜校准及复杂曝光合并尚未建模。拼接图、透明画布和多排非特异条带应回溯源图；不要把展示用拼图当作连续原始泳道。

网站内置示例与公开验证素材仅含合成图片。私有图片或结果不会成为网页预载内容、公开截图或仓库示例。
