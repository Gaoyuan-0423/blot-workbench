# 截图与版本证据 / Screenshot provenance

此目录用于保存实际运行截图。不得用设计稿、竞品界面或拼接图冒充本项目运行结果；截图也不代替功能测试。

| 文件 | 内容 | 证据元数据 |
| --- | --- | --- |
| `app-home.png` | 本项目本地网页演示首页 | 待补实际采集时间、本机 URL、应用版本、commit、系统、浏览器版本 |
| 仓库首页（文件名 `repository-home.png`） | 等待实际创建仓库后采集；当前不嵌入不存在的图片 | 待记录实际地址、采集时间、可见分支/commit 和浏览器版本 |

只有对应文件实际生成并检查后，才能将其视为已提供。当前文档占位不代表已截图、已上线或已通过验收。

![应用首页](app-home.png)

应用与仓库截图都必须在相应页面实际运行后采集。不得创建虚假 GitHub 仓库截图，也不以拟用地址代替已经存在的仓库。

English: capture the actual application and repository after each is available. Do not fabricate a repository screenshot or embed an absent image. Record capture date, URL, version/commit, OS, and browser. Pending metadata is not verification evidence. Screenshots do not establish quantitative accuracy or platform coverage.
