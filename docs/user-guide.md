# 使用指南

> 单页 8/16-bit TIFF 或 8-bit PNG/JPEG 的简易分析见[单条带指南](single-strip.md)与[多排／内参指南](quick-mode.md)。完整原图项目位于 `#real`，参见[真实图像指南](real-images.md)。本页步骤针对 `#demo` 的旧合成示例；个体 N/T 配对、共同基准及可选检验见[统计说明](paired-statistics.md)。

[English guide](user-guide.en.md) · [本机视觉 API 指南](vision-api.md) · [文档目录](README.md)

本指南说明已发布 `0.1.0-alpha.1` 和开发版 `0.2.0-dev.1` 共用的合成数据手动流程；公开网页与下载包仍是 `0.1`。所有示例图像与定量结果均为合成演示。界面的“确认”表示用户已检查某项配置，不表示其通过了科研验证。

## 打开独立教程

在开发版侧栏点击 **使用教程 / User guide**，打开独立 `#guide` 页面；教程与主界面一起跟随右上角 **EN / 中文** 切换。使用默认本机地址时，也可直接打开 `http://127.0.0.1:4318/#guide`；自定义端口时使用终端地址加 `#guide`。这个新入口尚未加入公开 `0.1` 网页，在线演示用户可阅读当前仓库指南。

开发版的 **视觉 API 设置** 是另一个可选入口，仅用于内置合成图接口测试，不运行以下项目的自动分析。配置步骤、外发内容与计费边界见[完整 API 指南](vision-api.md)。

## 1. 载入一个项目

打开[在线演示](https://gaoyuan-0423.github.io/blot-workbench/)，无需安装；也可按 [README](../README.md#本地运行与开发)在本机启动。首次打开网页会载入内置示例，后续会尝试恢复当前工作区。也可使用“打开项目”导入本版本导出的 `.wbproj.zip` 项目包。**这是项目包导入，不是任意 TIFF/PNG 图像导入。**

当前浏览器只保存一个工作区。新建项目、载入示例或导入项目会替换当前工作区，先点击“导出项目”保留原有内容。新建空项目用于讨论项目入口，不能继续导入真实图像。

选择合法项目包后，应用先校验文件并显示“替换当前工作区？”对话框，不会立即替换。可以“先导出当前项目”、取消，或点击“确认导入”后再替换。文件损坏或校验不通过时会报告错误，原工作区保持不变。

项目是跨日期、跨批次的组织单位。示例中的 2 个批次与 8 张图像都属于同一个项目。先查看项目说明和待检查事项，再进入图像。

## 2. 检查样本关系

查看样本与分组，核对每条泳道所对应的样本和实验单位。示例有 6 个样本、6 个实验单位；后一个批次复用这些样本。再次上样、重复成像或另一次曝光不会产生新的独立实验单位。

分组标签用于整理，不会替用户选择统计检验。日期只是批次属性；本演示不计算推断统计或显著性。

编辑样本名或项目名后，输入停顿时会自动提交并保存，无需先点击别处。清空必填名称不会保存空值，字段失去焦点时恢复上一个有效值；复核备注可以留空。

## 3. 检查图像与区域

选择批次和图像，核对目标/内参角色、膜和曝光信息。检查条带区域与背景区域是否符合这张图的示意内容；弱带、背景不均及饱和示例是预设场景标签，当前不是自动检测结果。

饱和图 `a-target-4000` 始终没有有效示例结果，即使取消排除也不能确认或导出定量。

ROI 指分析区域。调整区域后应看到分析变为待处理/失效（`stale`），旧模拟结果不得继续作为有效的当前结果。预置数值只用于原始演示配置，移动 ROI 不会运行真实像素积分。

检查目标图的内参配对。泳道编号相同不充分证明是同一个样本，必须同时考虑样本、膜及实验设计。无法确认的条目应保持未确认或排除，并记录原因。

## 4. 复用与修改模板

模板是可复用的初始设置。每次分析保留当时的模板快照和版本；修改当前模板不应更改旧分析。重新应用模板属于一次明确的分析修改，应重新检查区域和结果状态。

保存同值模板、应用完全相同的快照，或在设置和状态均未变时恢复示例，不会制造额外版本；状态确有变化仍会保留修订。

可以批量复用布局或设置，但每张图的条带位置、饱和与配对仍需检查。几何布局相似不等于实验意义相同。

## 5. 查看模拟结果

在“结果与记录”查看计算流程、净信号、目标/内参比值与相对值；积分、区域面积和背景均值字段见导出的 CSV。所有数值来自固定合成图的默认区域，必须被理解为预置 `DEMO` 数据；[方法文档](methods.md)解释生成方式与适用边界。

导出 CSV 前，目标图和它对应的内参图都必须“确认复核”，且分析仍匹配示例配置。未确认、排除或失效的数据不会形成有效导出行。内参修改会影响配对目标的结果状态。

下载的 `example.wbproj.zip` 从全部待复核状态开始。附带 `example-results.csv` 是完成所有 7 张可用图复核后的预期结果，共 18 行；它不是导入后立即可导出的状态。6 个实验单位在这 18 行中重复出现，不能按行数计算独立 n。

排除或失效的分析不应被当作有效结果导出。若界面提示配置与演示预设不一致，请保留修改用于讨论流程，或重新载入原始示例查看预置数值；不要把模拟输出解释为重新测量。

## 6. 保存、导出与回来继续

修改后浏览器自动保存，备注、样本名和项目名在输入停顿后提交，无需先让输入框失去焦点。顶部在内容尚未写入浏览器存储时显示“正在保存”；看到“已保存到本机”后再刷新或离开。未完成保存时离开页面会触发浏览器的离开确认提示，可以选择留在页面等待保存。

长期保留或迁移时仍应导出项目包。项目包包含图像、ROI、配对和参数快照；CSV 只用于查看结果表格，不能替代项目备份。

重新打开同一站点、同一浏览器时，可以检查恢复的项目、选中图像和分析状态。也可以导入导出的项目包。重新开始工作时，先阅读未确认/失效条目与备注，再继续检查。

浏览器本地存储受站点地址和浏览器配置影响。在线演示与本机地址使用不同的存储，彼此不会自动同步。使用无痕窗口、清除缓存/站点数据、切换浏览器或站点域名，都可能无法找到之前的项目。需要迁移时使用项目包，不依赖浏览器缓存。
