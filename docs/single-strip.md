# 单条带识别

独立的单排条带栏目，入口为 `?mode=single`。网站首页 `/` 和合成演示的左侧导航均可进入。完整分析在 `#real`，原项目演示在 `#demo`（兼容 `?mode=project`），多排及内参分析在 `?mode=quick`。

1. 导入、拖入或粘贴一张裁好的单排条带图。支持 8-bit PNG/JPEG，最大 15 MB；保留条带上下和左右空白。
2. 页面自动判断深浅背景、识别泳道，显示取样框和扣背景后的相对强度，默认泳道 1 为 1。
3. 检查取样框，导出结果图（PNG）或 CSV。需要修改时展开“识别不准？调整取样”；可改数量、图像类型、对照及框坐标。拖框和方向键也能调整位置。

多排图片会要求先裁成单排，不会自动选取其中一排。当前栏目不做内参归一化或统计检验；对应功能另有入口。没有有效条带或背景时不补造数值。无效格式导入失败会保留上一张图，并明确提示。

图片只在浏览器处理，当前分析不自动保存，刷新前请导出。结果为尚未经真实实验图像验证的 8-bit 像素估计，自动取样需核对。

2026-10-16，单条带测试随主线完整测试集运行。单条带用例包含真实 PNG 解码、已知像素积分、浅/深背景、多排拒绝、错误文件保留、默认折叠、结果导出和移动端布局。测试数据为合成图，不代表实验图像识别准确率。
